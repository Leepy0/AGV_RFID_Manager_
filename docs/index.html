설치·사용 설명서

1시작하기 전에 확인할 것

  • 안드로이드 휴대폰이어야 합니다 (갤럭시 등). 아이폰에는 설치되지 않습니다.
  • 휴대폰에 NFC 기능이 있어야 합니다. 최근 몇 년 사이에 나온 갤럭시는 거의 다 있습니다. (삼성페이·교통카드가 되는 휴대폰이면 있습니다.)
  • 안드로이드 8.0 이상이어야 합니다. 2018년 이후 휴대폰이면 대부분 됩니다.
  • 앱을 내려받고 업데이트할 때만 인터넷이 필요합니다. 태그를 읽고 쓰는 데는 인터넷이 필요 없습니다.
걸리는 시간내려받기부터 설치까지 보통 3~5분입니다. 중간에 나오는 경고 문구는 모두 정상이며, 아래에 하나씩 처리 방법을 적어 두었습니다.

2앱 파일 내려받기

이 앱은 플레이스토어에 올라가 있지 않고, 회사 저장소(GitHub)에서 직접 내려받아 설치합니다. 그래서 휴대폰이 "모르는 앱"이라고 몇 번 경고를 띄우는데, 모두 정상입니다.

  1. 휴대폰에서 이 페이지를 엽니다. 컴퓨터에서 보고 있다면 이 페이지 주소를 카카오톡 등으로 휴대폰에 보낸 뒤, 휴대폰에서 누릅니다.
  2. 맨 위의 파란 📥 앱 내려받기 버튼을 누릅니다.
    이런 화면이 나오면 파란 버튼이 GitHub 사이트로 연결되는 경우가 있습니다. 그러면 화면을 아래로 내려 Assets라는 글자를 찾고, 그 아래의 AGV_RFID_Manager_v….apk 파일 이름을 누르세요. (Assets가 접혀 있으면 한 번 눌러 펼칩니다.)
  3. 브라우저 경고가 뜨면 "다운로드(유지)"를 누릅니다.
    화면에 이런 문구가 보이면 "이 파일 형식은 휴대전화에 해를 끼칠 수 있습니다. AGV_RFID_Manager_….apk 파일을 유지하시겠습니까?"
    → 유지 또는 다운로드를 누릅니다. (크롬 기준. 삼성 인터넷은 "파일이 휴대전화에 해를 끼칠 수 있습니다" → 다운로드)
    앱 설치 파일(.apk)을 받을 때 항상 나오는 문구입니다. 이 앱 자체에 문제가 있다는 뜻이 아닙니다.

    이 파일 형식은 휴대전화에 해를 끼칠 수 있습니다. AGV_RFID_Manager_v2.3.1.apk 파일을 유지하시겠습니까?

    취소유지
    예시 화면 (크롬). 삼성 인터넷은 버튼 이름이 "다운로드"입니다.
  4. 다운로드가 끝나면 알림이 뜹니다. 알림을 누르거나 열기를 누릅니다.
    알림을 놓쳤다면 휴대폰의 내 파일(또는 파일) 앱을 열고 → 다운로드 폴더 → AGV_RFID_Manager_v….apk 파일을 누르세요. 크롬에서는 오른쪽 위 ⋮ → 다운로드에서도 찾을 수 있습니다.

3앱 설치하기 — 경고 문구 처리 방법

내려받은 파일을 누르면 설치가 시작됩니다. 휴대폰 종류와 설정에 따라 아래 화면 중 일부만 나올 수도 있고, 순서가 조금 다를 수도 있습니다. 나오는 화면을 찾아 그대로 하시면 됩니다.

3-1. "이 출처의 앱을 설치할 수 없습니다" (가장 많이 나옴)

화면에 이런 문구가 보이면 "보안상의 이유로 휴대전화에서 이 출처의 알 수 없는 앱을 설치할 수 없도록 설정되어 있습니다."
또는 "출처를 알 수 없는 앱 설치 — 보안을 위해 … 허용되지 않습니다."
대신 이런 문구가 보이면 (일부 휴대폰) "휴대전화와 개인 데이터는 알 수 없는 앱의 공격에 더욱 취약합니다. 이 앱을 설치하면 … 사용자가 책임을 진다는 것에 동의하게 됩니다."
→ 계속을 누르면 바로 3-2로 넘어갑니다. 아래 1~3단계는 건너뛰세요.
  1. 그 화면의 설정 버튼을 누릅니다. (설정 앱이 자동으로 열립니다.)
  2. "이 출처 허용" 스위치를 켭니다. 스위치가 파란색(또는 초록색)이 되면 켜진 것입니다.
    이게 무슨 뜻인가요?"크롬(또는 내 파일) 앱이 내려받은 설치 파일로 앱을 설치해도 된다"는 허락입니다. 지금 사용하는 크롬·내 파일 같은 앱에만 허락하는 것이라서 휴대폰 전체 보안이 꺼지는 것이 아닙니다.
  3. 휴대폰의 ◀ 뒤로 버튼을 누릅니다. 그러면 설치 화면으로 돌아옵니다. (돌아오지 않으면 내려받은 파일을 다시 한 번 누르세요.)

3-2. "이 앱을 설치하시겠습니까?"

화면에 이런 문구가 보이면 "AGV Tag Reader — 이 애플리케이션을 설치하시겠습니까?"
→ 설치를 누릅니다. 몇 초 뒤 "앱이 설치되었습니다"가 나오면 끝입니다. 열기를 누르세요.

이미 이 앱이 깔려 있는 휴대폰이라면 "기존 애플리케이션을 업데이트하시겠습니까? 기존 데이터는 삭제되지 않습니다."라고 나옵니다. 마찬가지로 설치(또는 업데이트)를 누르면 됩니다. 작업 기록과 설정은 그대로 남습니다.

3-3. Play 프로텍트 경고 — "인식할 수 없는 앱" / "앱을 차단했습니다"

구글이 플레이스토어에 없는 앱을 설치할 때 띄우는 경고입니다. 문구가 몇 가지 종류가 있습니다.

① "차단됨" 또는 "인식할 수 없는 앱"이라고 나올 때 "Play 프로텍트에서 이 앱을 차단했습니다 / 이 앱은 알 수 없는 개발자가 만든 앱입니다"
→ 작은 글씨의 자세히 알아보기(또는 세부정보)를 먼저 누르면 아래에 무시하고 설치 버튼이 나타납니다. 그것을 누르세요.

3-4. 갤럭시 "자동 차단" (설치 자체가 막힐 때)

최신 갤럭시(One UI 6 이상)에는 자동 차단이라는 기능이 있어서, 켜져 있으면 설치 파일을 눌러도 설치가 아예 안 됩니다.

화면에 이런 문구가 보이면 "자동 차단이 켜져 있어 앱을 설치할 수 없습니다" / "승인되지 않은 출처의 앱 설치가 차단되었습니다"
  1. 휴대폰 설정 앱을 엽니다. (톱니바퀴 모양)
  2. 보안 및 개인정보 보호를 누릅니다.
  3. 자동 차단을 누르고, 맨 위의 스위치를 끕니다.
  4. 내려받은 파일을 다시 눌러 설치합니다. 설치가 끝난 뒤에는 자동 차단을 다시 켜도 됩니다. (이미 설치된 앱과 앱 안의 업데이트에는 영향이 없습니다.)

4처음 실행하기 — NFC 켜기

이 앱은 휴대폰의 NFC(가까이 대면 통신하는 기능)로 태그를 읽고 씁니다. NFC가 꺼져 있으면 앱 맨 위 카드가 빨간색으로 "NFC가 꺼져 있어요"라고 알려 줍니다.

  1. 빨간 카드 안의 NFC 설정 열기를 누릅니다. 휴대폰 설정의 NFC 화면이 열립니다.
  2. NFC 및 비접촉 결제(또는 NFC) 스위치를 켭니다.
  3. ◀ 뒤로를 눌러 앱으로 돌아옵니다. 카드가 파란색 "읽기 대기"로 바뀌면 준비 완료입니다.

"패키지가 유효하지 않습니다"		 예전에 다른 방법(개발용 컴퓨터 등)으로 설치했던 같은 앱이 남아 있을 때 생깁니다. 기존 AGV Tag Reader 앱을 먼저 지우고(18번) 다시 설치하세요. 이 경우 작업 기록은 사라집니다.

"이 휴대전화와 호환되지 않는 앱입니다" 안드로이드 8.0 미만이거나 NFC가 없는 휴대폰입니다. 이 휴대폰에는 설치할 수 없습니다.
파일을 눌러도 아무 일도 없음 갤럭시 자동 차단이 켜져 있을 가능성이 큽니다. 3-4를 보세요. 그래도 안 되면 내 파일 앱 → 다운로드 폴더에서 파일을 눌러 보세요.
내려받기 자체가 안 됨 / 끝없이 기다림 회사 와이파이가 외부 사이트를 막는 경우가 있습니다. 와이파이를 끄고 모바일 데이터로 받아 보세요.
설치는 됐는데 아이콘을 못 찾겠음 홈 화면에서 위로 쓸어 올리면 나오는 앱 목록에서 AGV Tag Reader를 찾으세요. 위쪽 검색창에 "AGV"라고 쳐도 됩니다.

6앱 업데이트하기

새 버전이 나오면 앱을 다시 내려받을 필요 없이 앱 안에서 바로 업데이트할 수 있습니다. 앱을 열 때(그리고 앱으로 돌아올 때) 자동으로 새 버전이 있는지 확인합니다.

  1. "업데이트가 있어요" 창이 뜨면 업데이트를 누릅니다. 지금 바쁘면 나중에를 눌러도 됩니다. 다음에 앱을 열면 다시 물어봅니다.
  2. 내려받는 동안 잠시 기다립니다. 진행 막대가 끝까지 차면 설치 화면이 자동으로 열립니다.
  3. 처음 한 번은 "설치 허용이 필요해요"가 나옵니다. 설정 열기를 누릅니다.
    이어서 나오는 설정 화면에서AGV Tag Reader의 이 출처 허용 스위치를 켠 다음 ◀ 뒤로를 누르세요. 앱으로 돌아오면 설치 화면이 바로 열립니다.
    (3-1에서는 "크롬"에게 허락했고, 이번에는 "AGV Tag Reader 앱 자신"에게 허락하는 것이라 한 번 더 묻습니다. 두 번째 업데이트부터는 나오지 않습니다.)
  4. "기존 애플리케이션을 업데이트하시겠습니까? 기존 데이터는 삭제되지 않습니다." → 설치(또는 업데이트)를 누릅니다. Play 프로텍트 경고가 나오면 3-3과 같이 처리하세요.
  5. "앱이 업데이트되었습니다" → 열기. 작업 기록, 프리셋, 설정은 모두 그대로 남습니다.

앱 아래쪽 설정 탭 → 맨 아래 정보 → 업데이트 확인을 누르세요. 그 줄 아래에 결과가 나옵니다.

7화면 구성 한눈에 보기

앱은 아래쪽 탭 3개로 나뉩니다. 평소 작업은 모두 태그 탭에서 합니다.

위치하는 일
① 상태 카드 (맨 위 큰 카드)지금 상태(읽기 대기 / 쓰기 대기 / 읽기 완료 / 쓰기 완료 / 오류)와 읽거나 쓴 코드를 크게 보여 줍니다. 색으로도 구분됩니다: 파랑=대기·완료, 주황=쓰기 대기, 초록=읽기 완료, 보라=연속 쓰기, 빨강=오류·NFC 꺼짐.
② 코드 입력태그에 쓸 4자리 코드를 넣는 칸입니다. 오른쪽 목록을 누르면 자주 쓰는 코드를 골라 넣을 수 있습니다.
③ 프리셋자주 쓰는 코드 5개를 저장해 두고 한 번에 불러오는 칸입니다.
④ 최근 작업최근에 읽고 쓴 기록 3개. 전체를 누르면 전부 봅니다.
⑤ 쓰기 버튼 (맨 아래 큰 버튼)짧게 누르면 1장 쓰기, 길게 누르면 연속 쓰기가 시작됩니다.
⑥ 탭 (맨 아래)태그 작업 화면 / 가이드 사용법·에러 코드 / 설정
폴드·태블릿화면이 넓으면 상태 카드와 입력 칸이 좌우로 나란히 배치됩니다. 쓰는 방법은 똑같습니다.

8태그 코드란?

바닥 태그 한 장에는 4자리 코드가 한 개 들어 있습니다. AGV는 이 코드를 읽고 "여기서 멈춰라", "우회전해라" 같은 동작을 합니다.

0T21
0첫째 자리
숫자 0~9 또는 A~F T커맨드 타입
알파벳 1글자 21번호
두 자리 숫자 00~99

앱의 코드 입력 칸도 이 세 부분으로 나뉘어 있습니다. 평소에는 첫째 자리 0, 커맨드 타입 T를 그대로 두고 번호 두 자리만 바꾸는 경우가 대부분입니다.

9태그 읽기

읽기는 버튼을 누를 필요가 없습니다. 앱을 켜 둔 채 휴대폰 뒷면을 태그에 대면 바로 읽습니다.

  1. 앱을 열고 태그 탭에서 상태 카드가 "읽기 대기"인지 확인합니다.
  2. 휴대폰 뒷면 가운데~위쪽을 태그에 바짝 댑니다. 1초 정도면 "삑" 소리와 짧은 진동이 울리고, 카드가 초록색 "읽기 완료"로 바뀌며 코드가 크게 보입니다. 읽은 시각이 "14:31:02에 읽음"처럼 초 단위까지 표시됩니다.
  3. 읽은 코드를 입력 칸으로 가져오려면 초록 카드를 한 번 누르세요. 코드 입력 칸이 그 코드로 바뀝니다. (읽은 태그와 같은 값을 다른 태그에 쓰거나, 번호만 조금 바꿔 쓸 때 편합니다.)
인식이 잘 안 되면
  • 휴대폰마다 NFC 안테나 위치가 다릅니다. 보통 뒷면 가운데나 카메라 바로 아래입니다. 천천히 위아래로 움직여 잘 되는 위치를 찾아 두세요.
  • 두꺼운 케이스, 카드 지갑형 케이스, 금속 플레이트(거치대용 자석판)가 붙어 있으면 잘 안 됩니다. 벗기고 해 보세요.
  • 읽는 도중 휴대폰을 떼면 "통신 오류 — 태그가 떨어졌어요"가 나옵니다. 다시 대면 됩니다.

10태그에 쓰기 (1장)

10-1. 쓸 코드 넣기 — 네 가지 방법 중 편한 것으로

방법하는 법
프리셋 누르기 (가장 빠름)프리셋 칸(0T01 0T04 …)을 누르면 그 코드가 바로 들어갑니다. 선택된 칸은 파란 테두리로 표시됩니다.
목록에서 고르기코드 입력 오른쪽 목록 → 원하는 코드(예: "우회전 90도")를 누릅니다.
번호만 바꾸기번호 칸 옆 − + 버튼으로 숫자를 1씩 바꿉니다. 장갑을 끼고도 누를 수 있게 크게 만들었습니다.
직접 입력번호 칸을 누르면 키패드가 나옵니다. 두 자리 숫자를 치세요. 첫째 자리 칸은 0~9, A~F 한 글자. 가운데 커맨드 타입 칸은 누르면 T I O B D 중에서 고르는 메뉴가 나옵니다.
읽은 값 가져오기태그를 읽은 뒤 초록 상태 카드를 누르면 그 코드가 입력 칸에 들어갑니다. 최근 작업 줄을 눌러도 됩니다.
I ↔ O 빠르게 바꾸기커맨드 타입이 I나 O일 때 그 칸을 길게 누르면 서로 바뀝니다. 교통제어 IN/OUT 태그를 번갈아 쓸 때 메뉴를 열지 않아도 됩니다.

10-2. 쓰기

  1. 입력 칸에 원하는 코드가 들어 있는지 확인합니다. 맨 아래 쓰기 버튼에도 같은 코드가 표시됩니다.
  2. 쓰기 버튼을 짧게 한 번 누릅니다. 상태 카드가 주황색 "쓰기 대기 — 쓸 태그에 휴대폰을 대세요"로 바뀝니다.
  3. 5초 안에 휴대폰 뒷면을 태그에 댑니다. "삑" 소리와 함께 파란색 "쓰기 완료"가 나오고, 아래에 "0T01 → 0T21 · 검증 OK"처럼 이전 값 → 새 값이 표시됩니다.
    검증 OK란?쓴 직후 태그를 한 번 더 읽어서 정말 그 값이 들어갔는지 확인했다는 뜻입니다. 기본으로 켜져 있고, 설정에서 끌 수 있습니다.
주의
  • 쓰기는 태그의 기존 값을 덮어씁니다. 엉뚱한 태그에 대지 않도록 쓰기 대기 중에는 휴대폰을 다른 태그 근처에 두지 마세요.
  • 쓰기 대기 상태에서 태그를 대지 않고 5초가 지나면 "시간 초과"가 되고 아무것도 쓰지 않습니다. 다시 쓰기를 누르면 됩니다.
  • 쓰기 대기를 취소하려면 맨 아래의 쓰기 취소를 누르세요.
  • "검증 실패 — 0T21 ≠ 0T01"이 나오면 쓰는 도중 휴대폰이 떨어진 것입니다. 태그를 더 안정적으로 대고 한 번 더 쓰세요.

11연속 쓰기 (여러 장에 같은 값)

같은 코드를 태그 여러 장에 써야 할 때, 매번 쓰기를 누르지 않고 태그만 차례로 대면 됩니다.

  1. 쓸 코드를 입력 칸에 넣습니다.
  2. 맨 아래 쓰기 버튼을 길게(1초쯤) 누르고 있습니다. 진동이 울리고 상태 카드가 보라색 "연속 쓰기 중 — 다음 태그를 대세요"로 바뀝니다.
  3. 태그를 한 장씩 차례로 댑니다. 한 장이 끝나면 "삑" 소리와 "쓰기 완료"가 잠깐 보였다가 1초 뒤 자동으로 다시 "연속 쓰기 중"으로 돌아갑니다. 그러면 다음 태그를 대세요. 연속 쓰기 중에는 시간 제한이 없습니다.
  4. 다 썼으면 맨 아래 연속 쓰기 종료를 누릅니다.
주의연속 쓰기 중에는 휴대폰이 닿는 모든 태그에 같은 값이 써집니다. 끝났으면 반드시 연속 쓰기 종료를 누르고, 종료 전에는 다른 태그 위를 지나가지 않도록 하세요. 연속 쓰기 중에 입력 칸의 코드를 바꾸면 그 뒤부터는 바뀐 코드가 써집니다.

12잘못 썼을 때 되돌리기

쓰기 완료 직후 상태 카드 아래에 되돌리기 (0T01)처럼 이전 값이 적힌 버튼이 보입니다.

  1. 되돌리기 (이전 값)를 누릅니다. 이전 값으로 "쓰기 대기" 상태가 됩니다.
  2. 방금 썼던 같은 태그에 다시 댑니다. 이전 값으로 돌아갑니다.

되돌리기 버튼은 값이 실제로 바뀐 직후에만 나옵니다. 이미 다른 태그를 읽거나 쓴 뒤라면 작업 기록에서 이전 값을 확인해 직접 다시 쓰세요. (기록 줄에 "0T01 → 0T21"처럼 남아 있습니다.)

13프리셋 (자주 쓰는 코드 저장)

프리셋 칸 5개에는 처음에 0T01 0T04 0T07 0T21 0T22가 들어 있습니다. 현장에 맞게 바꿀 수 있습니다.

  • 불러오기: 칸을 짧게 누르면 그 코드가 입력 칸에 들어갑니다.
  • 저장하기 (방법 1): 먼저 입력 칸에 저장할 코드를 넣고, 프리셋 칸을 길게 누릅니다. "프리셋 저장됨: 0T05"라고 뜹니다.
  • 저장하기 (방법 2): 프리셋 오른쪽 편집을 누르면 칸들이 주황 테두리로 바뀝니다. 이때 칸을 짧게 누르면 현재 입력 칸의 코드가 저장됩니다. 다 됐으면 완료.

프리셋은 휴대폰에 저장되므로 앱을 껐다 켜도 그대로입니다.

14작업 기록

읽고 쓴 내용이 시각(시:분:초)과 함께 자동으로 남습니다. 프리셋 아래 최근 작업에 3건이 보이고, 전체를 누르면 전체 기록(최근 100건)이 나옵니다.

🔴 검증 실패썼지만 다시 읽은 값이 달랐음 → 다시 써야 함

  • 기록 줄을 누르면 그 코드가 입력 칸에 들어갑니다.
  • 전체 기록 화면 위쪽의 모두 지우기로 기록을 비울 수 있습니다.
  • 메인 화면에 최근 작업이 안 보이게 하려면 설정 → 메인 화면 이력 표시를 끄세요.

아래쪽 가이드 탭에는 이 설명서의 요약(앱 안내)과 AGV 에러 코드 표가 있습니다.

17자주 생기는 문제와 해결

태그를 대도 아무 반응이 없어요
  1. 상태 카드가 빨간 "NFC 꺼짐"이면 NFC를 켜세요 (4번).
  2. 앱이 화면에 떠 있어야 읽습니다. 다른 앱이 앞에 있거나 화면이 꺼져 있으면 읽지 않습니다.
  3. 휴대폰 뒷면의 다른 위치로 천천히 옮겨 보세요. 케이스·금속판을 떼어 보세요.
  4. 태그 자체가 손상됐을 수 있습니다. 정상인 다른 태그로 시험해 보세요.
"통신 오류 — 태그가 떨어졌어요"

읽거나 쓰는 도중에 휴대폰이 태그에서 떨어진 것입니다. 소리가 날 때까지 휴대폰을 움직이지 말고 다시 대세요. 쓰기 중이었다면 작업 기록에 "쓰기"가 남았는지 확인하고, 없으면 다시 쓰세요.

"검증 실패"가 자주 나요

쓰기는 됐지만 확인 읽기에서 값이 다르게 나온 경우입니다. 대부분 휴대폰을 너무 빨리 뗀 것입니다. 소리가 난 뒤 0.5초 정도 더 대고 있어 보세요. 같은 태그에서 계속 실패하면 태그 불량일 수 있습니다.

"시간 초과"가 나요

쓰기를 누른 뒤 5초 안에 태그를 대지 않은 것입니다. 태그에 휴대폰을 먼저 가져간 다음 쓰기를 누르는 순서로 하면 편합니다. 아무것도 써지지 않았으니 그냥 다시 하면 됩니다.

엉뚱한 태그에 써 버렸어요

쓰기 완료 직후라면 되돌리기를 누르고 그 태그에 다시 대세요 (12번). 시간이 지났다면 작업 기록에서 "이전 값 → 새 값"을 보고 이전 값을 직접 다시 쓰세요.

연속 쓰기가 안 켜져요 (짧게 눌러도 1장만 써요)

쓰기 버튼을 1초 정도 꾹 누르고 있어야 합니다. 진동이 울리고 카드가 보라색으로 바뀌면 켜진 것입니다. 손을 너무 빨리 떼면 1장 쓰기로 동작합니다.

업데이트 확인이 "확인 실패"로 나와요

인터넷 연결을 확인하세요. 회사 와이파이는 외부 사이트를 막는 경우가 많으니 모바일 데이터로 바꿔서 다시 눌러 보세요. 새 버전을 올리는 중인 1~2분 사이에도 잠깐 실패할 수 있습니다.

업데이트를 받았는데 설치 화면이 안 열려요

"설치 허용이 필요해요" 창에서 설정 열기 → 이 출처 허용을 켜고 ◀ 뒤로로 앱에 돌아와야 설치 화면이 열립니다. 그래도 안 되면 앱을 완전히 닫고 다시 열어 설정 → 업데이트 확인을 한 번 더 누르세요.

화면이 느리거나 버벅여요

설정 → 화면 효과 → 저사양으로 바꾸세요. 흐림·그림자 효과를 꺼서 오래된 휴대폰에서도 부드럽게 동작합니다.

앱이 갑자기 꺼졌어요

다시 열면 됩니다. 반복되면 설정 → 크래시 로그 → 공유로 기록을 담당자에게 보내 주세요. 앱 버전(설정 맨 아래)도 함께 알려 주세요.

18앱 지우기

  1. 홈 화면이나 앱 목록에서 AGV Tag Reader 아이콘을 길게 누릅니다.
  2. 삭제(또는 제거, 휴지통 모양)를 누르고 확인.

작업 기록과 프리셋도 함께 지워집니다. 3-1에서 켰던 "이 출처 허용"은 앱을 지워도 그대로 남으니, 원하면 휴대폰 설정 → 앱 → 크롬 → 알 수 없는 앱 설치에서 다시 끌 수 있습니다.
