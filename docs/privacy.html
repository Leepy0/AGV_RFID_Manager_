AGV Tag Reader 개인정보처리방침

시행일: 2026년 10월 26일

수집하는 개인정보

AGV Tag Reader(이하 "앱")는 이름, 연락처, 위치, 기기 식별자 등 어떤 개인정보도 수집하지 않습니다.

외부 전송

앱에는 인터넷 권한이 없어 어떤 정보도 외부 서버나 제3자에게 보내지 않습니다. 광고, 분석, 추적 도구를 쓰지 않습니다.

기기에 저장하는 정보

앱은 다음 정보를 휴대폰 안에만 저장합니다. 앱을 삭제하거나 설정 > 초기화를 누르면 지워집니다.

  • 앱 설정 (테마, 언어, 진동·소리 등)
  • 프리셋과 최근 작업 기록 (태그 코드, 시각)
  • 오류 기록 (앱 문제 확인용. 사용자가 설정 > 크래시 로그에서 직접 공유할 때만 기기 밖으로 나갑니다)

Android 기본 백업 기능이 켜져 있으면 위 정보가 사용자 본인의 Google 계정 백업에 포함될 수 있습니다. 이 백업은 Google이 관리하며 개발자는 볼 수 없습니다.

권한

  • NFC: AGV 바닥 RFID 태그를 읽고 쓰는 데만 씁니다.
  • 진동: 읽기·쓰기 결과를 알려 줍니다.

변경과 문의

이 방침이 바뀌면 이 페이지를 고치고 시행일을 새로 적습니다. 문의는 GitHub Issues로 남겨 주세요.

Privacy Policy (English)

AGV Tag Reader does not collect any personal data. The app has no internet permission, so it sends nothing to any server or third party. It uses no ads, analytics, or tracking.

Settings, presets, recent work history (tag codes and times) and error logs are stored only on the device. Error logs leave the device only when the user shares them from Settings > Crash log. They are deleted when the app is uninstalled or reset from Settings. If Android backup is enabled, this data may be included in the user's own Google account backup, which the developer cannot access.

Permissions: NFC is used only to read and write AGV floor RFID tags. Vibration is used to report results.

Changes to this policy will be posted on this page with a new effective date. Questions: GitHub Issues.
